## HAI3 CODE 視覺（2026-11-07 定案）

- **條碼**：一個簡稱＝一條直線，5 條一樣高，**越粗越強**（線寬＝欄寬 × 6%／14%／26%／46%／82%，每升一分大約粗一倍，1 分像髮絲、5 分像磚）。每條線下面寫簡稱＋分數（例：驚4），像真條碼底下的數字，不用看說明也讀得懂；第 5 條「推」用橘紅，是整條唯一的顏色。不用高低柱（2026-11-07 改：高低柱看起來像訊號格，組起來不像條碼）。
- **簡稱對照**（圖卡／網站用自家圖形，貼文文字用 emoji）：

| 簡稱 | 問的是 | 貼文 emoji | 自家圖形 |
|---|---|---|---|
| 驚 WOW | 有沒有讓人「哇」的東西 | 🤯 | 放射短線 |
| 氛 VIBE | 氣氛、音樂、人 | 🪩 | 鏡面球格點 |
| 順 EASY | 好不好去、停車、排隊 | 🛼 | 平滑箭頭 |
| 值 VALUE | 錢和時間值不值 | 🪙 | 收據撕邊 |
| 推 PICK | SS 推不推 | 📌 | 橘紅實心圓點 |

- BEST WOW／VIBE／EASY 直接用前三個 emoji。不用 🌺🌊🦁 這類典型沖繩 emoji。
- **文字版條碼**（貼文用）：分數 1–5 對到 `▏▎▌▊█`（越粗越強），後面一定接簡稱＋分數，例：`HAI3 CODE  ▊█▌▊█  驚4 氛5 順3 值4 推5`，下一行 `🤯4  🪩5  🛼3  🪙4  📌5`。
- **素材**：條碼、圖形、貼紙、膠帶、盲盒框、票根全部由 `tools/brand_assets.py` 生成到 `assets/brand/`（總覽 `assets/brand/index.html`，對照表 `assets/brand/code.json`），**改生成器再重跑，不手改 SVG**。Sona 副本在 `SonaSNS-Platform/assets/brandbook/hai3/`。

## 語氣規則：書面繁中，但有個性

有個性的來源是**敢下判斷、句子短、中英混搭**，不是方言。

- **直接給結論**：「去這間。」「這間可以跳過。」「日落前 30 分鐘到。」
- **短句**：一句只講一件事。卡片上最多兩行。
- **中英混用**（台港年輕人都習慣）：BEST VIBE、No Top 10、Just 3、MOOD。英文只用在標籤和口號，內文還是中文。
- **不講客套話**：不用「超美」「必去」「絕對不能錯過」「CP 值爆表」這類旅遊網站用爛的形容。改成具體的理由，例如「窗邊四個位子正對日落」。
- **用詞兩邊都懂**：選台港都通的說法，例如停車（不用「泊車」）、計程車／taxi（不用「的士」）、揀→選／挑。
- 可以偶爾用一個大家都看得懂的港式字當品牌小彩蛋（例如限動貼紙），但**不能出現在標題和正文裡**。
